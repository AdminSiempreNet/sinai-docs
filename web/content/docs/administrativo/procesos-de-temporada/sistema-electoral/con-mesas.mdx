## Guía paso a paso

En una elección con mesas, cada estudiante vota desde la mesa y el puesto de votación que tiene asignado.

1. Cree la elección y configure sus fechas, cargos y candidatos.
2. Registre las mesas y puestos de votación requeridos.
3. Asigne los estudiantes a la mesa y puesto correspondientes.
4. Revise el censo antes de abrir la votación.
5. Durante el proceso, use las consultas de seguimiento para verificar participación y resultados.

No modifique las asignaciones cuando la votación esté abierta, salvo que el procedimiento institucional lo autorice.
