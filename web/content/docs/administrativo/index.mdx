Este módulo reúne las guías para las personas que administran los procesos académicos e institucionales en SINAI. Aquí encontrará orientaciones para configurar la institución, gestionar información del personal y la matrícula, realizar seguimiento, planear, evaluar, promover y usar las herramientas de la plataforma.
