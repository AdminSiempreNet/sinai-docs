## Guía paso a paso

### Calificación Definitiva Directa

La **calificación definitiva directa** permite registrar las calificaciones de los estudiantes en una asignatura, a través de una planilla emergente. Es importante recordar que el acceso a esta funcionalidad está controlado por el cronograma asignado al grupo. Si el sistema no está habilitado para el periodo correspondiente, aparecerá un mensaje en una franja amarilla en la parte inferior de la pantalla indicando: **"El ingreso de nota directa no está habilitado para el periodo seleccionado".**

Adicionalmente, las calificaciones registradas a través de este módulo quedarán bloqueadas con el código **ND (Nota Directa)** para diferenciarlas de otras calificaciones.

Desde el módulo administrativo ingrese por el menú: **Evaluación  – Calificaciones – Calificación** **Definitiva Directa** <GuideImageTrigger src={"/images/wordpress/2025/02/Calificacion-Definitiva-Directa-1.png"} alt={"Captura de Calificacion Definitiva Directa 1"}>Ver ejemplo</GuideImageTrigger>



#### Cómo Registrar la Nota Directa

**Seleccionar el Docente, Grupo, Periodo y Asignatura**

- **Docente**: Facilita la elección del grupo correspondiente.
- **Grupo**: seleccione el grupo para el cual se registrarán las calificaciones.
- **Periodo**: Define el periodo académico en el cual se realizará el registro.
- **Asignatura**: seleccione la asignatura para la que se desea registrar las calificaciones.

**Registrar la Calificación a cada Estudiante**

- Registra la **calificación definitiva** de cada estudiante.
- Si es necesario, puede registrar la **inasistencia** de los estudiantes o añadir **observaciones** relacionadas con su rendimiento.

**Pulsar el Botón "Guardar":** Una vez que hayas ingresado todas las calificaciones y observaciones necesarias, seleccione el botón **"Guardar"** para almacenar los datos ingresados. <GuideImageTrigger src={"/images/wordpress/2025/02/Calificacion-Definitiva-Directa-2-1024x359.png"} alt={"Captura de Calificacion Definitiva Directa 2"}>Ver ejemplo</GuideImageTrigger>



#### Procesos Complementarios en la Planilla

##### Botón "Actividades"

Botón **Actividades**: Generalmente se registra una sola calificación, pero si se requiere colocar varias, al pulsar este botón permite registrar una actividad y genera otra casilla de calificación en la planilla.

**Pasos para Agregar Actividades**

- Escoge el **orden** en que se debe registrar la actividad.
- **Escribe el nombre de la actividad**.
- haga clic en **Agregar**.
- Si desea **modificar** una actividad, guarda los cambios.
- Si desea **eliminar** una actividad, marca la actividad y haga clic en **Eliminar** <GuideImageTrigger src={"/images/wordpress/2025/02/Calificacion-Definitiva-Directa-3.png"} alt={"Captura de Calificacion Definitiva Directa 3"}>Ver ejemplo</GuideImageTrigger>



##### Botón Importar

proceso de **importación de notas** permite traer las calificaciones registradas previamente desde fuentes externas a la planilla de calificación definitiva directa. Esta opción facilita la actualización de las calificaciones sin necesidad de ingresarlas manualmente.

Las fuentes externas disponibles para la importación de calificaciones son:

1. **Tareas en Línea**
2. **Autoevaluación del módulo estudiante**
3. **Aula virtual Chamilo**

A continuación se detallan los pasos para realizar la importación de notas

##### Pasos para Importar las Notas

1. **Seleccione el Origen de las Notas:**

    - Al pulsar el botón **"Importar"**, se abrirá un menú donde podrá seleccionar el origen de las notas que desea importar.
    - Las opciones disponibles son:
        - **Tareas en Línea**
        - **Autoevaluación del módulo estudiante**
        - **Aula virtual Chamilo**
2. **Seleccione la Tarea:**

    - Después de seleccionar el origen, el siguiente paso es elegir la **tarea** donde se encuentran las calificaciones.
    - En este paso, se desplegarán las tareas disponibles dentro del origen seleccionado.
    - Escoge la tarea cuyo contenido desea importar.
3. **Seleccione la Actividad:**

    - Una vez seleccionada la tarea, debe elegir la **actividad** asociada con las calificaciones que desea importar.
    - Asegúrate de seleccionar la actividad correcta para importar las notas que desea transferir a la planilla.
4. **Importar las Notas:**

    - Después de seleccionar la tarea y la actividad, haga clic en la opción **"Importar Notas"**.
    - El sistema transferirá automáticamente las calificaciones desde la fuente seleccionada a la planilla de **Calificación Definitiva Directa**. <GuideImageTrigger src={"/images/wordpress/2025/02/Calificacion-Definitiva-Directa-4.png"} alt={"Captura de Calificacion Definitiva Directa 4"}>Ver ejemplo</GuideImageTrigger>



#### Botón Eliminar y Actualizar Configuración

##### **Eliminar:**

- -   Si necesitas eliminar alguna calificación, inasistencia o observación registrada, puede seleccionar el registro correspondiente y hacer clic en **"Eliminar"** para eliminarlo permanentemente.

##### **Actualizar Configuración"**

- -   Si has realizado cambios en la configuración de la planilla, como la adición de nuevas actividades o la modificación del orden de las calificaciones, es necesario pulsar **"Actualizar configuración"**.
    - Esto asegurará que los cambios realizados se reflejen en la planilla. <GuideImageTrigger src={"/images/wordpress/2025/02/Calificacion-Definitiva-Directa-5.png"} alt={"Captura de Calificacion Definitiva Directa 5"}>Ver ejemplo</GuideImageTrigger>
