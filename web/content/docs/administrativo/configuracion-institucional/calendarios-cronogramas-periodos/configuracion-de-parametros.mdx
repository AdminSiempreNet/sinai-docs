## Guía paso a paso

### 1\. Configuración Académica

La **configuración académica** es el proceso mediante el cual se define la intensidad horaria y el peso porcentual de cada asignatura dentro de un área. Esta información sirve como base para la asignación académica y la organización curricular.

En la plataforma SINAI, puede realizar este proceso siguiendo esta ruta: **Menú Establecimiento > Configuración Académica > Configuración Académica** <GuideImageTrigger src={"/images/wordpress/2025/01/1-Configuracion-academica.png"} alt={"Captura de Configuracion academica"}>Ver ejemplo</GuideImageTrigger>



En la sección de configuración académica encontrará dos pestañas principales:

- **Áreas y Asignaturas**
- **Componentes de la Evaluación**

#### 2\. Áreas y Asignaturas

Esta sección permite configurar las áreas y asignaturas, especificando su intensidad horaria (HS) y peso porcentual (%).


El contenido se organiza en columnas: la primera columna muestra el nombre del área, seguida por otra columna con las asignaturas que pertenecen a esa área. Frente a cada área y asignatura, se encuentran los niveles educativos: Preescolar, Primaria, Secundaria, Media, Adultos y Normal.


Para cada nivel, hay dos columnas adicionales que detallan:

- **El número de horas semanales** asignadas a cada asignatura.
- **El peso porcentual** de esa asignatura dentro del área correspondiente. <GuideImageTrigger src={"/images/wordpress/2025/01/3-Configuracion-academica.png"} alt={"Captura de Configuracion academica"}>Ver ejemplo</GuideImageTrigger>



#### 3\. Componentes de la Evaluación

Facilita la definición de los criterios y componentes que se aplicarán para la evaluación académica.

Muestra el número de componentes definidos por la institución educativa, junto con su nombre y el peso porcentual asignado a cada uno. <GuideImageTrigger src={"/images/wordpress/2025/01/6-Configuracion-academica.png"} alt={"Captura de Configuracion academica"}>Ver ejemplo</GuideImageTrigger>



#### 4\. Actividades Predeterminadas

Especifica el número máximo de casillas asignadas a ese componente. En las instituciones que utilizan actividades ponderadas, también indica el peso porcentual correspondiente a cada actividad. <GuideImageTrigger src={"/images/wordpress/2025/01/7-Configuracion-academica.png"} alt={"Captura de Configuracion academica"}>Ver ejemplo</GuideImageTrigger>



#### 5\. Escala Especial para Preescolar

Define la equivalencia de cada nivel de desempeño, permitiendo realizar una valoración cualitativa basada en la escala de la institución. Esta opción es editable y, una vez realizados los cambios o modificaciones, es necesario hacer clic en el botón **Guardar** para aplicarlos. <GuideImageTrigger src={"/images/wordpress/2025/01/8-Configuracion-academica.png"} alt={"Captura de Configuracion academica"}>Ver ejemplo</GuideImageTrigger>
