## Guía paso a paso

Esta opción genera el listado de estudiantes que tienen requisitos pendientes en la plataforma.

## 1. Accede al reporte

En el módulo **Administrativo**, ingresa a **Matrícula > Listados > Requisitos Pendientes**.

## 2. Selecciona la fecha de consulta

Verifica o ajusta la fecha mostrada en el campo de consulta. El reporte tendrá en cuenta los requisitos pendientes registrados hasta esa fecha.

## 3. Descarga el listado

Selecciona el formato que necesitas:

- **PDF:** genera el reporte para consulta o impresión.
- **Excel:** descarga la información para trabajarla en una hoja de cálculo.

> **Nota:** si el visor de reportes muestra un mensaje de configuración, intenta descargar el archivo nuevamente o valida con el administrador de la plataforma la configuración del visor de informes.
