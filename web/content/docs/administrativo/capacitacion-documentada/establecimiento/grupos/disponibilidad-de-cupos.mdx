## Guía paso a paso

La disponibilidad de cupos es un formato que dispone SINAI para que se asigne el número de **cupos asignados** para cada grupo y así poder observar la disponibilidad de los mismos. https://youtu.be/-bRPTkMCgb0?si=G7iXvc6A0bLJZx8A En esta guía aprenderás a configurar y asignar la disponibilidad de cupos en la plataforma **SINAI**. Para realizar este proceso, ingresar al menú  **Establecimiento > Grupos > Disponibilidad de Cupos**. <GuideImageSequence images={[ { src: "/images/wordpress/2025/01/1-Disponibilidad-de-cupos.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/2-Disponibilidad-de-cupos_.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/3-Disponibilidad-de-cupos.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/4-Disponibilidad-de-cupos_.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/5-Disponibilidad-de-cupos_.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/6-Disponibilidad-de-cupos_.png", alt: "Captura de Disponibilidad de cupos" }, { src: "/images/wordpress/2025/01/7-Disponibilidad-de-cupos_.png", alt: "Captura de Disponibilidad de cupos" }, ]} > Ver ejemplos </GuideImageSequence>
