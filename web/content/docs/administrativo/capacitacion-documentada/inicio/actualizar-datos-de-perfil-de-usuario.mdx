## Guía paso a paso

En este artículo veremos cómo actualizar los datos de perfil del usuario, cambiar la contraseña del usuario.

La actualización de datos de perfil está disponible haciendo clic en el nombre de usuario que está en la parte superior derecha de la ventana de **SINAI**. Se desplegará una ventana emergente en la que podrá hacer clic en el botón Perfil. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-1.png"} alt={"Captura de Perfil 1"}>Ver ejemplo</GuideImageTrigger>



Al hacer clic en el botón **Perfil** verá una ventana con la información básica del usuario y otras opciones. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-2.png"} alt={"Captura de Perfil 2"}>Ver ejemplo</GuideImageTrigger>



### Actualizar la fotografía

Para actualizar la fotografía del usuario siga estos pasos.

- Cuando ingresemos a nuestro perfil nos ubicaremos en la parte izquierda de nuestra pantalla, donde podemos visualizar nuestra foto de perfil y la opción seleccionar archivo, para cargar nuestra foto preferida directamente desde nuestro ordenador. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-3.png"} alt={"Captura de Perfil 3"}>Ver ejemplo</GuideImageTrigger>



- Cuando hayamos elegido nuestra foto de perfil daremos clic en el botón abrir y posteriormente en el botón cargar, tal como se muestra en las siguientes imágenes. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-4-1024x449.png"} alt={"Captura de Perfil 4"}>Ver ejemplo</GuideImageTrigger>

 Nota Esta fotografía solo actualiza la foto de perfil del usuario, pero si la institución tiene activada la configuración para permitir que los funcionarios actualicen la fotografía, también se actualizará la foto del funcionario respectivo. ×

#### Actualizar Información Básica

1. Diligencie los datos básicos como nombres, apellidos, tipo de identificación, número de identificación, etc.
2. Asegúrese de escribir correcta y completamente la dirección de correo electrónico y el número de teléfono. Recuerde que estos son los datos que usará SINAI para recuperar la contraseña.
3. El correo institucional utilizado para el ingreso a la plataforma es administrado por la institución educativa. La contraseña inicial es una **contraseña institucional** que asignan los administrativos al crear el usuario y se envía al correo registrado; ya no es la palabra "sinai". Si necesita restablecerla, SINAI enviará a ese correo un enlace para modificarla directamente.
4. El apartado datos del funcionario, son importantes para clasificar el tipo de vinculación u otros que el usuario tenga con la institución.
5. Finalice haciendo clic en el botón **Guardar Cambios.**

#### Registrarse con Snet Core

SNET CORE centraliza los accesos a las demás plataformas con una sola cuenta.

Si aún no se ha registrado en Snet Core, seleccione [**Gestionar cuenta Snet Core**](https://www.sinai.net.co/MigracionCore/InicioMigracion.aspx), junto al botón **Guardar cambios**. Al ingresar, seleccione **Registrarse**. También encontrará el enlace en el recuadro de abajo para copiarlo y abrirlo en el navegador.

El siguiente proceso que debemos realizar es ingresar nuestros datos básicos, ya que la plataforma nos pedirá cierta información para después validar nuestra identidad, estos son procedimientos de seguridad, por ende, es necesario ingresar información verídica para no tener errores en el proceso. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-5.png"} alt={"Captura de Perfil 5"}>Ver ejemplo</GuideImageTrigger>



para seguir el proceso pulsaremos el botón continuar, ingresamos los datos pertinentes, damos clic en la casilla he leído las [políticas de seguridad](https://ayudasinai.siempre.net.co/politica-de-privacidad/) y finalizáremos en el botón registrarme.

El último proceso es validar nuestros datos para poder tener gestión e ingreso desde Snet Core, para este paso vamos a pulsar el botón validar datos que será reflejado cuando hayamos finalizado el paso anterior, la información entregada anteriormente como correo electrónico y número de celular será utilizada para enviar un código de seguridad y validar la identidad, este es el paso final para registrarnos con Snet Core desde nuestro perfil de usuario.

Nota Este proceso de validación de datos no es un requisito para registrarse simplemente es un paso de verificación de información.

La primera vez que ingrese a SINAI mediante la cuenta creada en SNET CORE, el sistema solicitará vincularla con el usuario habitual de SINAI. Ingrese el usuario, que normalmente corresponde a su número de documento, y la contraseña utilizada en el inicio de sesión tradicional. Esta asociación se realiza una sola vez; después podrá ingresar con SNET CORE sin repetirla. <GuideImage src="/images/guides/inicio-sesion/vinculacion-snet-core.png" alt="Formulario de vinculación entre SNET CORE y un usuario de SINAI" caption="Confirme las credenciales habituales de SINAI para completar la vinculación inicial." size="medium" />

#### ¿Puedo cambiar mi nombre de usuario?

De forma predeterminada, ningún usuario de SINAI puede cambiar su nombre de usuario. El nombre de usuario es el documento de identidad de la persona. Solo en casos especiales es posible cambiar el nombre del usuario y este procedimiento solo puede hacerse directamente por parte del personal de servicio al cliente del operador de la plataforma SINAI. Puede realizar una solicitud a través de alguno de los Canales de servicio al cliente.

#### Registro de actividad

El registro de actividad es la lista de acciones realizadas por el usuario a lo largo de su acceso a **SINAI**. No todas las acciones son auditadas, por lo que no todas aparecen en el registro de actividad.

Para ver el registro de actividad haga clic en la pestaña «**Registro de Actividad**» que aparece en la parte superior del perfil de usuario, tal como se muestra en la siguiente imagen. <GuideImageTrigger src={"/images/wordpress/2024/07/Perfil-6-1024x449.png"} alt={"Captura de Perfil 6"}>Ver ejemplo</GuideImageTrigger>
