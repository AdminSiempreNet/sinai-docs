## Guía paso a paso

### Trasladar una Asignación Académica

En el menú principal “Personal” Encontramos la opción “Trasladar Asignación”, esta agiliza el proceso para trasladar la asignación académica y dirección de grupo de un docente a otro, siempre y cuando se haya creado con anticipación el funcionario del nuevo docente.

Este proceso es práctico, por ejemplo, cuando se presenta el traslado o permuta de docentes, ahorrando el tiempo que implica crear la asignación académica desde cero. <GuideImageTrigger src={"/images/wordpress/2023/11/Trasladar-asignacion-1024x408.png"} alt={"Captura de Trasladar asignacion"}>Ver ejemplo</GuideImageTrigger>
