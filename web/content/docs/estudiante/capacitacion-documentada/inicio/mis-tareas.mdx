## Guía paso a paso

El estudiante, en su módulo, cuenta con un apartado para recibir y entregar las tareas asignadas por sus docentes. A continuación, se explica el procedimiento de forma detallada.

**En el módulo del estudiante o acudiente haga clic en el menú** **Inicio >** **Mis tareas** (disponible en el panel izquierdo o a través del ícono correspondiente).

[<img alt="Captura de MIS TAREAS 1" src="/images/wordpress/2025/02/MIS-TAREAS-1.png" />](/images/wordpress/2025/02/MIS-TAREAS-1.png)

### Exploración del Módulo

Al ingresar a **Mis Tareas**, se encuentra una interfaz con diversos filtros y opciones para gestionar las actividades.

[<img alt="Captura de MIS TAREAS 2" src="/images/wordpress/2025/02/MIS-TAREAS-2.png" />](/images/wordpress/2025/02/MIS-TAREAS-2.png)

1. Seleccione el **Grupo, Período, Asignatura y Estado** para filtrar el listado de tareas.
2. Use el botón **"Limpiar filtros"** para restablecer los campos de búsqueda.
3. Visualice las tareas disponibles según los criterios seleccionados.
4. Consulte el **número de tareas terminadas**, permitiendo identificar posibles atrasos en la entrega.

#### Realizando una Tarea

Al seleccionar una tarea, se despliega la información detallada proporcionada por el docente.

[<img alt="Captura de MIS TAREAS 3" src="/images/wordpress/2025/02/MIS-TAREAS-3.png" />](/images/wordpress/2025/02/MIS-TAREAS-3.png)

1. Se visualizan las orientaciones del docente para realizar la tarea o el contenido mismo de la tarea según lo establezca.
2. Se visualizan los documentos adjuntos disponibles para su **descarga**.
3. Detalles de la tarea: **período**, **docente responsable**, **plazo de entrega**, **fecha de cierre**, **estado de envío** y **calificación (si ya ha sido evaluada)**.

#### Seguimiento y entrega de la tarea

El sistema permite hacer un seguimiento detallado de cada tarea antes y después de su envío.

[<img alt="Captura de MIS TAREAS 4" src="/images/wordpress/2025/02/MIS-TAREAS-4.png" />](/images/wordpress/2025/02/MIS-TAREAS-4.png)

1. Revise el seguimiento automático que genera el sistema durante el proceso de la tarea.
2. Escriba **observaciones o mensajes adicionales** con relación a la tarea si se considera necesario.
3. Cargue el archivo con la tarea desarrollada y asignarle un nombre.
4. Seleccione **"Enviar tarea"** para completar la entrega. Esto generará un seguimiento automático en el sistema.
5. Volver a la página de inicio para consultar el listado de tareas pendientes o enviadas.

📌 Notas importantes: ✔ Revisar siempre la fecha límite de entrega de cada tarea para evitar retrasos.
✔ Confirmar que el archivo enviado sea el correcto antes de realizar la entrega.
✔ Utilizar el espacio de observaciones para aclarar dudas o enviar comentarios al docente.
✔ Si se requiere modificar una tarea enviada, consultar con el docente si es posible reenvío.
