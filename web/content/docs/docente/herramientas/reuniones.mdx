## Guía paso a paso

1. Ingrese a **Herramientas > Gestión de reuniones**.
2. Cree una reunión e indique asunto, fecha, participantes y detalles requeridos.
3. Guarde la configuración y use el listado para consultar o modificar la reunión.
4. Registre acuerdos o evidencias cuando la pantalla lo permita.
