## Guía paso a paso

### Backup

Es una copia de respaldo de los datos originales que se realiza con el fin de disponer de un medio para recuperar dicha información en caso de una pérdida.

El sistema envía la copia al correo que el funcionario tiene configurado en su ficha de información. Se recomienda realizar copia de seguridad en cada periodo una vez tenga la certeza que los registros de calificaciones estén al 100%.

Esta opción en plataforma la encontramos por dos menús (**Inicio > Backup y General > Backup)**

[<img alt="Captura de Backup" src="/images/wordpress/2025/02/Backup-1024x300.png" />](/images/wordpress/2025/02/Backup.png)

En la ventana que se muestra se debe realizar lo siguiente

1. Se seleccione el nombre del docente.
2. El “**Periodo”** para el cual se va a realizar el Backup.
3. Correo electrónico del docente
4. Se seleccione sobre el botón “**Enviar**” y el sistema envía la copia al correo que se encuentra visible.
