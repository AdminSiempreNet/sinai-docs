## Guía paso a paso

1. Desde **Inicio > Mensajes**, abra la bandeja correspondiente.
2. Use el listado para identificar mensajes nuevos o pendientes.
3. Abra un mensaje para leerlo y responda o registre la acción solicitada cuando aplique.
4. Actualice la bandeja para comprobar que el mensaje fue gestionado.

El buzón permite comunicarse con estudiantes, docentes, directivos y personal administrativo según los permisos del usuario.
