## Guía paso a paso

1. Ingrese a **Evaluación > Informes**.
2. Seleccione el tipo de informe y complete los filtros solicitados.
3. Genere la vista previa para validar la información.
4. Descargue el archivo cuando la opción esté disponible.

Verifique grupo, período y asignatura antes de compartir el informe.
