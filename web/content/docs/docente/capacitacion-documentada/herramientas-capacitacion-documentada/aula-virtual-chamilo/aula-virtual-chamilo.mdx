## Guía paso a paso

### Aula Virtual

En la presente guía se va a conocer el procedimiento para ingresar al aula virtual **CHAMILO** desde el módulo del docente.


**Nota:** es preciso recordar que a esta opción sólo pueden ingresar los docentes de las Instituciones que hayan adquirido este servicio o herramienta.

#### ¿Cómo Ingresar al Aula Virtual CHAMILO desde SINAI?

Desde el módulo del docente, se debe ingresar al menú **“Herramientas”**, luego, seleccionar la opción **“Aula virtual”** tal como aparece en la siguiente imagen

[<img alt="Captura de Aula 1" src="/images/wordpress/2025/02/Aula-1-1024x452.png" />](/images/wordpress/2025/02/Aula-1.png)

Estando en el submenú **“Aula virtual”**, se encontrará habilitado un botón que dice **“Ingresar al Aula Virtual”** en el que daremos clic.

[<img alt="Captura de Aula 2" src="/images/wordpress/2025/02/Aula-2-1024x861.png" />](/images/wordpress/2025/02/Aula-2.png)
