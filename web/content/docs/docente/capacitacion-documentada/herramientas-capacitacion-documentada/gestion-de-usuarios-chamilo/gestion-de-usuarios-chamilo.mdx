## Guía paso a paso

1. Abra **Herramientas > Gestión de usuarios**.
2. Consulte el usuario, grupo o rol que necesita gestionar en Aula Virtual Chamilo.
3. Use las opciones habilitadas para crear, actualizar o sincronizar el acceso.
4. Verifique que el usuario y su rol quedaron asociados correctamente.

La disponibilidad de acciones depende de los permisos docentes y la configuración institucional del Aula Virtual.
