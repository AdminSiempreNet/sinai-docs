## Guía paso a paso

1. Abra **Herramientas > Informes digitales**.
2. Seleccione el informe, grupo y período requeridos.
3. Genere la vista previa y confirme la información.
4. Descargue o comparta el informe mediante las opciones habilitadas.

Compruebe que el período y los destinatarios sean correctos antes de realizar una distribución digital. Si el informe no muestra información, valide que el registro académico del grupo esté actualizado.
