## Guía paso a paso

1. Ingrese a **Ficha observador > Informes**.
2. Seleccione los filtros disponibles, como grupo, estudiante o período.
3. Elija el tipo de informe requerido.
4. Genere la vista previa y descargue el archivo cuando corresponda.

Revise la información antes de compartirla, pues contiene datos de seguimiento del estudiante.
