## Guía paso a paso

Si olvidó su contraseña de acceso a SINAI, puede restablecerla mediante una de las siguientes alternativas.

### 1. Recuperación automática desde SINAI

1. En la pantalla de inicio de sesión de SINAI, seleccione **Recuperar contraseña**.

<GuideScreenshot
  src="/images/wordpress/2024/09/1.-Recuperar-contrasena.png"
  alt="Opción Recuperar contraseña en la pantalla de inicio de SINAI"
  caption="Seleccione Recuperar contraseña para iniciar el proceso."
/>

2. Ingrese el correo electrónico registrado en SINAI y seleccione **Restablecer contraseña**. El sistema indicará a qué dirección se enviaron las instrucciones.

<GuideScreenshot
  src="/images/guides/inicio-sesion/ingresar-correo.png"
  alt="Campo para ingresar el correo electrónico registrado al recuperar la contraseña"
  caption="Ingrese el correo electrónico registrado en SINAI."
/>

3. Revise el correo electrónico recibido y siga el enlace para crear una nueva contraseña.

<GuideCallout>
  Si no tiene acceso al correo registrado, solicite apoyo a un rector, coordinador, secretario o administrador autorizado de su institución.
</GuideCallout>

### 2. Recuperación mediante SNET CORE

SNET CORE centraliza los accesos a otras plataformas con una sola cuenta. Use esta alternativa cuando ingresa a SINAI con una cuenta de SNET CORE.

1. Desde SINAI, seleccione **Iniciar con SNET CORE**.

<GuideImage
  src="/images/wordpress/2024/09/5-Recuperar-contrasena.png"
  alt="Acceso a SNET CORE desde SINAI"
/>

2. En la pantalla de inicio de SNET CORE, abra **¿Olvidaste tu contraseña?**.

<GuideScreenshotGrid>
  <GuideScreenshot
    src="/images/wordpress/2024/09/6-Recuperar-contrasena.png"
    alt="Inicio de sesión de SNET CORE"
    caption="Seleccione ¿Olvidaste tu contraseña? para iniciar la recuperación."
  />
  <GuideScreenshot
    src="/images/wordpress/2024/09/7-Recuperar-contrasena.png"

    caption="Escriba el correo electrónico registrado en SNET CORE."
  />

3. Escriba el correo electrónico usado durante el registro.
4. Abra el mensaje recibido y siga el enlace para definir una nueva contraseña.

### 3. Restablecimiento por un usuario administrativo

Si no puede recuperar la contraseña con las opciones anteriores, contacte a un directivo o administrador autorizado. SINAI enviará un enlace de restablecimiento al correo electrónico registrado.

La nueva contraseña debe tener mínimo **14 caracteres** e incluir una letra mayúscula, una letra minúscula y un número.
